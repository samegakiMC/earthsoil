==================================================
หมายเหตุ
==================================================

เว็บไซต์ใช้ภาพและวิดีโอจากแหล่งภายนอก
ดังนั้นต้องมีอินเทอร์เน็ตเพื่อให้ภาพและวิดีโอแสดงผล

ข้อมูลเหตุการณ์ภัยพิบัติที่กำลังเกิดขึ้นอาจมีการเปลี่ยนแปลง
ควรตรวจสอบข้อมูลจากแหล่งข่าวและหน่วยงานทางการก่อนนำไปใช้เป็นข้อมูลอ้างอิง

เว็บไซต์นี้จัดทำเพื่อการศึกษา
