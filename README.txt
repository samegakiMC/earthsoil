EARTHSOIL
เว็บไซต์ให้ความรู้เรื่องดินถล่มและดินเสื่อมโทรม

==================================================
โครงสร้างไฟล์
==================================================

index.html
หน้าแรกของเว็บไซต์

article.html
หน้าบทความแบบละเอียด

style.css
ไฟล์ตกแต่งเว็บไซต์ทั้งหมด

script.js
ระบบ Animation และระบบอ่าน URL

article.js
ข้อมูลบทความและระบบ Quiz

README.txt
คำอธิบายเว็บไซต์


==================================================
วิธีเปิดใน VS CODE
==================================================

1. เปิด VS Code

2. เปิดโฟลเดอร์ EARTHSOIL

3. ตรวจสอบว่าไฟล์ทั้งหมดอยู่ในโฟลเดอร์เดียวกัน

    index.html
    article.html
    style.css
    script.js
    article.js
    README.txt

4. เปิด index.html

5. ถ้ามี Live Server
   คลิกขวาที่ index.html

6. เลือก Open with Live Server

==================================================
ข้อควรระวัง
==================================================

ข้อมูลเกี่ยวกับเหตุการณ์ภัยพิบัติเป็นข้อมูลที่เปลี่ยนแปลงได้

หากนำเว็บไซต์ไปใช้เป็นรายงาน
ควรตรวจสอบข้อมูลข่าวสารล่าสุด
และอ้างอิงแหล่งข้อมูลที่เชื่อถือได้
