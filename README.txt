โครงสร้าง
- index.html — หน้าแรก
- article.html — หน้าบทเรียนแบบแตกแขนง
- article.js — ฐานข้อมูลบทเรียน/ตัวเรนเดอร์สำรอง
- quiz.html — แบบทดสอบ
- references.html — แหล่งอ้างอิง

เวอร์ชันนี้ฝัง CSS และข้อมูลบทเรียน fallback ไว้ใน HTML ด้วย จึงยังแสดงผลได้แม้เบราว์เซอร์ไม่อนุญาตให้โหลดไฟล์ภายนอกจาก archive
