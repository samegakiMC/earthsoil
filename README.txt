EARTHSOIL
เว็บไซต์ให้ความรู้เรื่องดินถล่มและดินเสื่อมโทรม

==============================
ไฟล์ภายในเว็บไซต์
==============================

index.html
หน้าแรกของเว็บไซต์

article.html
หน้าสำหรับอ่านบทความแบบละเอียด

style.css
ไฟล์ตกแต่งเว็บไซต์ทั้งหมด

script.js
ระบบ Animation และการอ่าน URL

article.js
ข้อมูลบทความทั้งหมด + ระบบ Quiz

README.txt
คำอธิบายเว็บไซต์


==============================
วิธีเปิดเว็บไซต์ใน VS CODE
==============================

1. เปิด VS Code

2. เลือก File > Open Folder

3. เลือกโฟลเดอร์ที่เก็บไฟล์ทั้งหมด

4. ตรวจสอบว่าไฟล์อยู่ในโฟลเดอร์เดียวกัน

    index.html
    article.html
    style.css
    script.js
    article.js
    README.txt

5. เปิด index.html

6. ถ้ามี Live Server
   คลิกขวาที่ index.html

   เลือก
   Open with Live Server


==============================
ความสามารถ
==============================

- หน้าแรก
- ระบบการ์ดหัวข้อ
- กดหัวข้อเพื่อดูรายละเอียด
- ระบบสารบัญด้านซ้าย
- เปลี่ยนบทความโดยไม่ต้องสร้าง HTML หลายหน้า
- URL สามารถเปิดหัวข้อโดยตรงได้

ตัวอย่าง:

article.html?topic=landslide

article.html?topic=degradation

article.html?topic=chemical

article.html?topic=human

article.html?topic=economy

article.html?topic=environment

article.html?topic=social

article.html?topic=prevention

article.html?topic=recovery

article.html?topic=data

article.html?topic=cycle

article.html?topic=quiz

==============================
ข้อมูลที่จำเป็นในการวิเคราะห์ดิน
==============================

- สภาพทางกายภาพของดินปัจจุบัน
- สภาพทางเคมีของดินปัจจุบัน
- ประวัติการใช้ที่ดิน
- พฤติกรรมของผู้ใช้ที่ดิน
- ลักษณะภูมิประเทศ
- ลักษณะภูมิอากาศ


==============================
แนวคิดสำคัญ
==============================

ดินเสื่อม
↓
ผลผลิตตกต่ำ
↓
รายได้ลด
↓
เพิ่มปัจจัยการผลิต
↓
ต้นทุนเพิ่ม
↓
ดินยังมีปัญหา
↓
เกิดภาระหนี้สิน
↓
ต้องใช้ที่ดินหนักขึ้น
↓
ดินเสื่อมมากขึ้น
